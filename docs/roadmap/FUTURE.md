# Future Roadmap

The ideas in this document are not part of the current implementation scope.

## BFF

A backend-for-frontend may be useful later to demonstrate data contracts, aggregation, and frontend-specific API design. It should wait until the core library and showcase are mature.

## Micro-Frontends

Micro-frontends may be explored only when there is a realistic reason to split applications. They should not be added as architecture decoration.

## Monorepo

A monorepo may become useful if the project grows into multiple packages or apps, such as `core`, `showcase`, `docs`, or `bff`.

## React Native

React Native support would require a separate strategy for primitives, styling, tokens, and platform differences.

## Devtools

Devtools could help inspect tokens, themes, or component usage in the future.

## CLI

A CLI could scaffold components, stories, tests, or docs once patterns are stable.

## AI-Assisted Docs

AI-assisted documentation may help generate examples or review docs, but generated content must still be verified.

## Design Token Pipeline

A token pipeline may be added if tokens need to move between design tools, code, and documentation.
