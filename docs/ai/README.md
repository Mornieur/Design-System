# AI Documentation

This directory provides operational guidance for AI agents working inside the FeitozaUI repository.

Use `docs/ai` for:

- repository-specific working rules;
- source-of-truth order;
- workflow guidance for public component work;
- review and validation expectations;
- version-aware official source references.

Do not move normative architecture or design-system rules into this folder. Those remain in:

- [`../architecture`](../architecture)
- [`../design-system`](../design-system)
- [`../STORYBOOK.md`](../STORYBOOK.md)
- [`../TESTING_STRATEGY.md`](../TESTING_STRATEGY.md)
