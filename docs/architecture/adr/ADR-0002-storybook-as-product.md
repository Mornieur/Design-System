# ADR-0002: Storybook As A Product Documentation Surface

## Status

Accepted

## Context

Storybook can be used only as a component preview tool, but FeitozaUI needs a professional documentation surface that explains foundations, usage, guidelines, accessibility, examples, and roadmap.

## Decision

Storybook will be treated as a product surface for documentation and component exploration.

## Consequences

- Stories should include useful states and examples, not only default renders.
- MDX documentation should be clear, current, and honest about project maturity.
- Storybook structure should support Overview, Getting Started, Foundations, Components, Accessibility, Guidelines, and Roadmap.
