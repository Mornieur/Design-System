# Security Policy

FeitozaUI is currently a portfolio project and is not published as a production dependency.

## Supported Versions

No published versions are officially supported yet.

| Version | Supported |
| --- | --- |
| Unpublished | No production support |

## Reporting A Vulnerability

Do not open a public issue for sensitive security reports.

Until a dedicated security contact is configured, use a private channel with the maintainer.

Before publishing, add a dedicated security contact in the GitHub repository settings.

## Secrets

Secrets must not be committed to the repository. Local registry tokens should live outside versioned files and should be rotated if exposed.
