## Future Installation

```bash
npm install @feitoza-ui/core
```

## Future Usage

```tsx
import { Button, Box, Flex, colors, space } from '@feitoza-ui/core';

export function AccountSummaryPanel() {
  return (
    <Flex align="center" gap={3}>
      <Box padding={4} radius="medium" bg="backgroundAlt">
        Account summary
      </Box>
      <Button variant="primary">Continue</Button>
    </Flex>
  );
}
```

## Development Scripts

```bash
yarn.cmd type-check
yarn.cmd lint
yarn.cmd test --run
yarn.cmd build
yarn.cmd storybook
```

## Current Package Surface

The public package surface currently includes foundational atoms, core molecules, and design tokens. Product-specific examples, runtime theming, BFF, and micro-frontends are intentionally outside the current package surface.
