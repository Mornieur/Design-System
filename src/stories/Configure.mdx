The current public API is intentionally small:

- `Button`
- `Box`
- `Flex`
- design tokens

This Storybook is the technical documentation surface for the platform. It should show what exists today, explain why decisions were made, and keep future work clearly separated from current capabilities.

## Not Current Scope

- BFF
- Micro-frontends
- Full theme system
- Complete component catalog
- Production showcase application

These ideas are documented as future directions, not as current features.

## How To Read This Storybook

- Start with Foundations to understand available tokens.
- Review Components for current public primitives.
- Use Guidelines and Accessibility before adding or changing components.
- Treat Roadmap as future direction, not as shipped capability.
