# Roadmap

This roadmap describes direction, not shipped functionality.

## Current

- Project positioning as a UI Engineering Platform.
- Core documentation and architecture decisions.
- Package build alignment.
- Public component surface aligned around atoms, core molecules, and tokens.
- Accessibility and behavior coverage across the active public surface.

## Next

- Surface primitives and Card 2.0.
- Documentation and repository polish.
- Continued accessibility and behavior coverage.
- Public package demonstration readiness.

## Later

- Showcase without backend.
- Performance and bundle analysis.
- Versioning and release process.
- Broader component set after primitives are stable.

## Future Ideas

- BFF
- Micro-frontends
- Monorepo
- React Native
- CLI
- Design token pipeline

These are intentionally out of scope for the current implementation phase.
