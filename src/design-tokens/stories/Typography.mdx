# Typography

Typography tokens currently define font families and a small font-size scale.

This is not a full text component system yet. Dedicated `Text` or `Heading` components may be added later after the foundation is stable.

## Usage Notes

- Keep component typography token-based.
- Avoid introducing new font families in component code.
- Treat full type scale and text components as future work.
