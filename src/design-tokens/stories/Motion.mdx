# Motion

Motion is short, functional, and tied to interface feedback.

| Token | Value |

## Easing

| Token | Value |
| --- | --- |
| `motion.easing.standard` | {motion.easing.standard} |
| `motion.easing.emphasized` | {motion.easing.emphasized} |

## Usage Notes

- Use `normal` for common hover, focus, and color transitions.
- Avoid ornamental motion in dense product UI.
- Respect reduced-motion preferences when introducing spatial animation.
