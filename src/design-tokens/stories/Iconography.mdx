# Iconography

FeitozaUI uses iconography as technical signal, not decoration. Icons should support scanning, state recognition, and action clarity.

## Rules

- Import icons directly from `lucide-react`; do not import a full icon bundle.
- Use `16px` for compact controls, table cells, and metadata.
- Use `20px` as the default component icon size.
- Use `24px` for navigation, prominent actions, or empty states.
- Keep stroke near `1.75` or the Lucide default unless optical correction is needed.
- Use `aria-hidden="true"` for decorative icons.
- Provide an accessible name for icon-only buttons through the interactive element.
- Do not use cyan on every icon.
- Do not use icons as the only state indicator.
