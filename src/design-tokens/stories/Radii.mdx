# 🟦 FeitozaUI Design Token — Radius Tokens

Corner radius tokens ensure consistency across buttons, cards, inputs and all UI surfaces.  
They define how rounded or sharp components should look throughout the design system.

---

# 📏 Radius Scale

- **small — {radii.small}**
- **medium — {radii.medium}**
- **large — {radii.large}**
- **round — {radii.round}** (perfect circle)

# 📐 Usage Guidelines

- **small** → subtle rounding for inputs, badges, micro UI  
- **medium** → default rounding for cards, buttons, fields  
- **large** → expressive rounding for surfaces (modals, elevated UI)  
- **round** → icons, avatars, and circular interactive elements
