# Colors

FeitozaUI currently exposes a small color foundation for brand, neutral, and feedback decisions.

These tokens are available to consumers today. A broader primitive/semantic token model is future work and should not be assumed to exist yet.

## Usage Notes

- Use color tokens through components when possible.
- Do not introduce new hardcoded colors inside reusable components without documenting the reason.
- Treat theme support as future work until semantic theme tokens are implemented.
