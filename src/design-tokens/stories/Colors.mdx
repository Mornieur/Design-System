# Colors

FeitozaUI colors follow the Quiet Future / Neon Infrastructure direction: dark infrastructure surfaces, quiet text roles, and controlled neon accents.

`colors` remains available as the default compatibility export. New work should prefer `primitiveColors` for raw values and `semanticColors` for intent.

## Usage Notes

- Use color tokens through components when possible.
- Do not introduce new hardcoded colors inside reusable components without documenting the reason.
- Treat runtime theme switching as future work until a ThemeProvider exists.
- Use semantic contrast text tokens for saturated action backgrounds.
