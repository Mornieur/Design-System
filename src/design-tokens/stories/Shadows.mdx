# Shadows

Elevation supports quiet separation on dark infrastructure surfaces. Neon shadow is reserved for deliberate accent moments.

| Token | Value |
| --- | --- |
| `shadows.none` | {shadows.none} |
| `shadows.sm` | {shadows.sm} |
| `shadows.md` | {shadows.md} |
| `shadows.lg` | {shadows.lg} |
| `shadows.focus` | {shadows.focus} |
| `shadows.neon` | {shadows.neon} |

## Usage Notes

- Use elevation for hierarchy, not decoration.
- Do not apply neon shadow to every surface.
- Keep focus treatment visible against dark and light surfaces.
