# Spacing

The spacing scale defines consistent distances for layout, component padding, margins, and gaps.

The current scale is compact and numeric.

## Usage Notes

- Use smaller values for compact UI.
- Use middle values for component padding and grid gaps.
- Use larger values for page sections and larger layout spacing.
