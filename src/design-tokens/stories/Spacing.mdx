# 📐 FeitozaUI Design Token — Spacing Tokens

The spacing scale defines consistent paddings, margins, and gaps used throughout the interface.  
These values help maintain visual rhythm and layout structure across components and pages.

---

# 📏 Spacing Scale

- **1 — {space[1]}**
- **2 — {space[2]}**
- **3 — {space[3]}**
- **4 — {space[4]}**
- **5 — {space[5]}**
- **6 — {space[6]}**
- **7 — {space[7]}**
- **8 — {space[8]}**

# 📘 Usage Guidelines

- Use smaller values (1–3) for compact internal spacing such as badges, icons, and tight UI layouts.  
- Use medium values (4–6) for component padding, grid gaps, and standard layout spacing.  
- Use larger values (7–8) for page sections, containers, and generous whitespace.
